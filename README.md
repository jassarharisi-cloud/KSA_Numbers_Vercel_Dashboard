# KSA Numbers — Vercel Dashboard

واجهة عربية RTL جاهزة للنشر على Vercel.

## ما تم بناؤه
- لوحة تحكم داكنة متجاوبة.
- بطاقات إحصائيات.
- نسبة تقدم الدفعة.
- حالة الاتصال بالمصدر.
- جدول النتائج مع البحث.
- زر رفع ملف وزر بدء البحث (واجهة).
- API health.
- `vercel.json` مهيأ لوظائف طويلة حتى 1800 ثانية في Pro/Enterprise مع Fluid Compute.

## نقطة هندسية مهمة
واجهة Vercel مناسبة للوصول من أي جهاز. أما محرك البحث الفعلي فيجب أن يعمل كـ Worker/Function مع تخزين خارجي للحالة والنتائج، حتى لا تعتمد العملية على جهاز المستخدم.

لـ 1024 رقم:
- يُفضل تقسيم المهمة إلى دفعات (مثل 25–100 رقم) أو Queue.
- حفظ الحالة في قاعدة بيانات/Redis.
- تحديث لوحة التحكم دوريًا.
- عدم تخزين كلمات المرور أو مفاتيح حساسة في الكود.
- أي CAPTCHA/تحقق يتم التعامل معه حسب سياسات المصدر ولا يتم تجاوزه آليًا.

## النشر
1. ارفع المشروع إلى GitHub.
2. اربطه بـ Vercel.
3. اختر Next.js.
4. Deploy.
